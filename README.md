# Jornada pela Biblia - site institucional

Site estatico provisorio de apresentacao do projeto Jornada pela Biblia, atualmente em desenvolvimento.

- `index.html`: pagina inicial responsiva, com apresentacao institucional e uma pequena demonstracao interativa de leitura.
- `favicon.svg`: identificacao grafica conceitual.
- `robots.txt`: orientacao basica para indexacao.

O site nao usa backend nem inclui o codigo-fonte do aplicativo. A integracao de voz da ElevenLabs e apresentada como prototipo e plano futuro, nao como parceria aprovada ou servico lancado.

Para publicar no GitHub Pages, configure Settings > Pages > Build and deployment > Deploy from a branch > main > /(root).

O dominio `jornadanabiblia.com.br` so deve ser vinculado depois de configurar o destino no GitHub Pages; nao altere registros de e-mail MX, SPF, DKIM ou DMARC do Zoho.
